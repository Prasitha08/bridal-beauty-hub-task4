BRIDAL BEAUTY HUB — TASK 03 & TASK 04

TASK 03: INTERACTIVE PROTOTYPE CREATION
- index.html: responsive clickable prototype.
- Flow: Welcome > Sign in / Guest > Explore services > Provider details > Booking form > Confirmation.
- My Bookings and Profile are also clickable from the top navigation.
- Includes mobile-responsive layouts and basic form validation.

TASK 04: USABILITY TESTING & ANALYSIS
- Usability_Testing_and_Analysis_Report.pdf: test plan, objectives, five test tasks,
  metrics, participant observation sheet, feedback questions, analysis framework,
  preliminary design review and improvement recommendations.
- usability_observation_template.csv: blank data-entry sheet for up to five participants.

IMPORTANT
This is an educational prototype. It does not include live authentication, a database,
payments, real providers or real booking submission. Names/prices are sample content.
The usability report is a test plan/template, not fabricated participant research.
Conduct the sessions and fill in the observation sheet before claiming measured results.
